## What I do

- Generate a postgresql Data Source Name from environment variables
- Provide a Data Source Name

## When to use me

- When a DSN is required to run a command
- When migrating the database

# DSN Generator Skill

Use the DSN generator tool to produce a PostgreSQL DSN from a `.env` file.

Providing no argument to the command will use the default .env for the project

The tool can be found in ./opencode/tools/
